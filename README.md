# Student Performance Analyzer

A console-based Java application that analyzes student exam results
and generates performance insights such as:

- Average score by topic
- Weak topics
- Declining performance trends
- Study recommendations

## Features
- Object-oriented design
- Multiple exams per student
- Topic-wise score analysis
- Trend detection across exams

## Technologies
- Java 8+
- Console-based application

## How to Run
```bash
javac *.java
java Main

Why this project?
This project was built to practice real-world Java concepts like
data modeling, aggregation, and performance analysis.
